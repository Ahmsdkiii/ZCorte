## O. Recommended Technology Stack

Legenda keputusan: **Pakai** / **Pakai (kondisional)** / **Tidak dipakai**.

| Teknologi                                     | Peran                                 | Alasan                                                                                                                        | Alternatif                 | Keputusan                                                                                                                                          |
| --------------------------------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Next.js App Router (v16 sesuai prototype)     | Framework fullstack                   | Sudah dipakai prototype; SSR/ISR, Server Actions, Route Handlers dalam satu repo                                              | Remix, Nuxt                | **Pakai**                                                                                                                                          |
| React 19, TypeScript `strict`                 | UI & tipe                             | Wajib brief; mengurangi bug                                                                                                   | —                          | **Pakai** (+ `noUncheckedIndexedAccess`)                                                                                                           |
| Node.js LTS                                   | Runtime                               | Prisma & Auth.js kompatibel                                                                                                   | Bun                        | **Pakai**                                                                                                                                          |

| shadcn/ui + Radix                             | Primitif UI admin/form                | Aksesibel, kode dimiliki sendiri (bukan dependency tebal)                                                                     | MUI, Mantine               | **Pakai (kondisional)**: hanya untuk owner & dialog form; storefront tetap komponen prototype                                                      |
| Lucide React                                  | Ikon                                  | Sudah ada; prototype juga punya `Icon` & SVG kustom                                                                           | Heroicons                  | **Pakai** (via `Icon` atom)                                                                                                                        |

> **Ketergantungan eksternal, versi & biaya.** R0 tidak menganggap AI, payment, cloud storage, Telegram, atau hosting tertentu tersedia. Versi package dikunci melalui `pnpm-lock.yaml` (`--frozen-lockfile` di CI) serta `engines`/`packageManager` di `package.json`; versi pasti dependensi baru (Prisma, Auth.js, Zod, Vitest, Playwright) dicatat saat Foundation P1. R1 hanya memilih provider setelah tim memverifikasi dokumentasi resmi terbaru, kuota, biaya, lokasi data, metode yang didukung, dan persyaratan akun.
